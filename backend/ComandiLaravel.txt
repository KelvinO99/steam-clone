Creare un progetto laravel da cmd
composer create-project laravel/laravel example-app


Attivare un progetto condiviso con git
Modifica env
composer i
composer dump-autoload

Attivare il progetto
php artisan serve
Creare una tabella:
php artisan make:migration create_users_table

Aggiornare tabella:
php artisan migrate:fresh

Creare Seeder:
php artisan make:seeder nomeseeder

Fare il Seed di tutto tramite DatabaseSeeder:
php artisan db:seed

Fare il Seed della singola classe (Singolo file Seeder, esempio: charcuterieSeeder.php):
php artisan db:seed --class=charcuterieSeeder

Creare una Factory:
php artisan make:factory nomefactory

Creare un modello:
php artisan make:model nomemodello

Creare un Controller:
php artisan make:Controller nomecontroller

Creare un Controller con le CRUD:
php artisan make:Controller nomecontroller --resource 

IMPORTANTE QUANDO CAMBI LE ROUTE STOPPA IL SERVER
composer dump-autoload
php artisan config:clear 
php artisan route:clear 
php artisan route:cache
php artisan serve
Installa jwt e cambia un fottio di cose prima di fare sto comando:
 php artisan make:controller AuthController

 Genera la secret key nel file env
 php artisan jwt:secret
